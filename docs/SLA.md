# 鲁品开拍 SLA（服务等级协议）

> 状态：草案。以下指标为**目标值**，待生产环境实测后校准。
> 当前阶段（第十二阶段）仅完成脚手架：指标采集（`/api/v1/metrics`）、
> 健康检查（`/api/health`、`/api/ready`）、用量报表均已就绪，
> 但生产流量数据尚未积累，**所有数字均为目标，非承诺**。

## 1. 可用性目标

| 指标 | 目标 | 说明 |
|---|---|---|
| API 月度可用性 | ≥ 99.5% | 以 `/api/health` 探测为准；计划内维护窗口除外 |
| AI 任务提交成功率 | ≥ 99% | 任务进入队列即算成功；模型侧失败不计入 |
| 数据持久性 | RPO ≤ 24h，RTO ≤ 4h | 见 `docs/SLO.md`、`docs/BACKUP_RESTORE.md` |

## 2. 延迟目标（P95）

| 接口类别 | P95 目标 | 备注 |
|---|---|---|
| 读接口（列表/详情） | ≤ 500ms | 数据库查询 |
| 写接口（创建/更新） | ≤ 800ms | 含事务提交 |
| AI 同步接口 | ≤ 120s | 受模型侧延迟影响，超时分级见代码 |
| 导出（DOCX/SRT） | ≤ 30s | 大作品可能更长，走异步导出 |

P95 数据来源：`GET /api/v1/metrics` 的按路由延迟分布（内存聚合，重启清零；
多实例部署后由 Prometheus 统一聚合）。

## 3. 维护窗口

- 常规维护：每周三 02:00–04:00（Asia/Shanghai），提前 24h 公告。
- 数据库迁移：先在预发布环境演练；不可逆变更用 expand-and-contract。
- 紧急修复：不受窗口限制，事后补公告与复盘。

## 4. 支持渠道

| 级别 | 响应目标 | 渠道 |
|---|---|---|
| P0（服务不可用/数据丢失风险） | 1h 内响应 | 待定（上线前确认值班电话/群） |
| P1（核心功能故障） | 4h 内响应 | 待定 |
| P2（一般问题/咨询） | 1 工作日内响应 | 待定 |

> 以上渠道上线前由运营确认，本阶段仅搭架子。

## 5. 免责范围

1. 第三方模型服务（deepkey / OpenAI 兼容接口）故障、限流、涨价导致的
   生成失败或延迟，不在 SLA 内；平台侧提供熔断、重试、预算控制与用量台账。
2. 用户自带 API Key 场景下，模型侧问题由用户自行排查。
3. 不可抗力（机房断电、骨干网故障、政策变化）导致的不可用。
4. 风险审核为"辅助检查 + 人工确认"，**不构成法律合规保证**（见产品内提示）。
5. AI 生成内容可能存在事实偏差；引用事实必须经事实库核实流程
  （status=confirmed 且 allow_use=true），否则不得作为宣传依据。

## 6. 赔偿

本阶段未定价（见计费脚手架说明：价格由运营配置）。赔偿条款待商业化
定价确定后补充。
