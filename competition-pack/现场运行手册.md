# 鲁品开拍 · 现场运行手册

## 一、启动前环境检查

```bash
# 1. Python 虚拟环境存在
ls ~/workspace/lupin-kaipai/venv/bin/uvicorn

# 2. 依赖完整（fastapi/uvicorn/python-docx/pydantic/requests/pyyaml）
~/workspace/lupin-kaipai/venv/bin/pip list 2>/dev/null | grep -iE "fastapi|uvicorn|docx|pydantic|requests|yaml"

# 3. 模型 API 配置存在（只检查文件存在，不输出内容）
ls -l ~/.omp/agent/models.yml
# 预期：-rw-------（600 权限，仅所有者可读）
```

## 二、启动命令

```bash
cd ~/workspace/lupin-kaipai
./venv/bin/uvicorn backend.app:app --host 0.0.0.0 --port 8931
```

- 本机访问：`http://127.0.0.1:8931/`
- `--host 0.0.0.0` 表示监听所有网卡；仅本机演示可改用 `--host 127.0.0.1`

## 三、确认前后端正常工作

```bash
# 后端健康检查（不消耗 API 调用）
curl -s http://127.0.0.1:8931/api/health
# 预期：{"status":"ok","model":"gpt-6-luna","ai_ready":true,...}
# ai_ready 为 false 表示 API Key 未配置，生成功能不可用，但页面可打开
```

前端确认：浏览器打开首页，看到"产品资料与拍摄条件"表单即正常。

## 四、检查模型 API 配置（不暴露密钥）

```bash
# 只验证连通性，不打印 Key
curl -s http://127.0.0.1:8931/api/health | python3 -c "import json,sys; d=json.load(sys.stdin); print('ai_ready:', d['ai_ready'], '| 已调用:', d['calls'], '次')"
```

**禁止**：`cat ~/.omp/agent/models.yml`、`grep apiKey`、截图含密钥、日志打印密钥。
Key 只在服务端启动时读入内存，从不返回给前端、不写日志（见 `backend/ai_service.py::load_api_key` 文档）。

## 五、演示前自检顺序

1. [ ] 服务启动，`/api/health` 返回 200 且 `ai_ready: true`
2. [ ] 浏览器打开首页，表单正常渲染
3. [ ] 点一次"生成创意方向"预热（可选，确认模型通路正常；注意消耗 1 次 API 调用）
4. [ ] 准备备用录屏（见《证据采集清单》#13）
5. [ ] 关闭无关标签页，浏览器开全屏

## 六、故障备用办法

| 故障 | 现象 | 备用办法 |
|------|------|---------|
| API 不可用 | `ai_ready: false` 或生成时报 502/鉴权失败 | 1. 检查 `~/.omp/agent/models.yml` 是否存在；2. 改用备用录屏演示 |
| 生成超时 | 转圈超过 2 分钟 | 说明"模型接口偶尔慢，不是卡死"；超过 3 分钟切录屏 |
| 导出失败 | 显示"分镜未通过校验" | 按错误提示调整（通常是总时长误差>2秒）；调好后重试 |
| 页面打不开 | 浏览器空白/拒绝连接 | 1. 确认服务在运行；2. 换 Firefox（Chrome 142+ 会拦截 localhost）；3. 切录屏 |
| 浏览器选型 | — | **推荐 Firefox**；Chrome 142+ 的本地网络检查会拦截 `http://127.0.0.1:8931`，属浏览器自身限制 |

## 七、其他设备访问（如需手机/投影仪）

**必须单独验证，不可仅凭本机能打开就声称其他设备能访问。**

```bash
# 1. 确认监听地址是 0.0.0.0（不是 127.0.0.1）
ss -tlnp | grep 8931
# 预期看到 0.0.0.0:8931

# 2. 查本机局域网 IP
hostname -I | awk '{print $1}'

# 3. 在目标设备浏览器打开 http://<局域网IP>:8931/
# 4. 确认防火墙放行 8931 端口
```

⚠️ **已知限制**：在某些云 VM / 容器环境，入站连接可能被网络策略拦截（如本项目的开发机 Tailscale 为纯客户端模式，不接受入站）。如目标设备打不开，改用本机演示 + 录屏备用。

## 八、清理演示数据

本项目**无数据库、无持久化**，所有状态在浏览器内存中。清理方法：

- 关闭浏览器标签页即清空（刷新页面也会重置）
- 如需清理导出的临时文件：`rm -f /tmp/tmp*.docx`（仅清理本项目导出的临时文件）
- **不得删除**：`~/workspace/lupin-kaipai/` 下的任何源代码、测试、demo 文件；不得动 `venv/`；不得动 `~/.omp/agent/models.yml`
